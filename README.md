# AroundTheBlock

AroundTheBlock is a cozy, single-page-at-a-time digital neighborhood for small, low-pressure moments of care. Each building offers a different kind of pause. There are no accounts, analytics, or saved entries; interactive text stays in the open page and is cleared when you leave or refresh.

## The neighborhood

- **The Worry Cloud Laundromat** (`index.html`) — Set down a heavy thought, choose a wash, and watch it dissolve into a pastel star.
- **The Nourish Café** (`cafe.html`) — Pick kind thoughts from the pantry and stack them on your plate.
- **The Studio Apartment** (`studio.html`) — Pause for grounding, reflection, breathing, or a small hobby.

Use the AroundTheBlock navigation at the top of each page to move between buildings.

## Open it locally

No installation, build step, or server is required. Open `index.html` in a modern browser, then use the neighborhood navigation to visit the other pages. You can also open `cafe.html` or `studio.html` directly.

## Built with

The pages use plain HTML, CSS, and vanilla JavaScript. They have no external framework, image, or audio dependencies. The laundromat illustration is drawn with Canvas; its optional finishing chime is synthesized in the browser. Layouts adapt to smaller screens and honor the operating system's reduced-motion preference.

## Privacy and intent

This is a sensory companion and creative pause, not care or treatment. It does not save thoughts or track history. Text entered into a page remains in that page's memory and disappears when the page is refreshed or closed.
